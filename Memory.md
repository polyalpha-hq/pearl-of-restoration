## «Интриги» — Фазы 7-9 (доверие через прозрачность)

Три инициативы, превращающие производственные данные в публичные доказательства. Цель: токенхолдер видит не маркетинг, а сырые факты — каждая партия, каждый объект, каждый дивиденд верифицируем on-chain.

### Фаза 7 — Proof-of-Processing

**Что:** Датчики на линии (расход сырья, температура, выход сорбента) пишут сырые показания в TON-блокчейн раз в N минут. Сайт показывает live-дашборд, читающий ту же цепочку.

**Зачем:** Инвестор может проверить, что линия действительно работает, без доверия к нам. «Производство X тонн в день» становится проверяемым, а не заявленным.

**Технически:**
- Edge-устройство (Raspberry Pi / промышленный шлюз) на линии
- Подписанный пакет показаний → smart-contract на TON
- Виджет на сайте читает контракт, показывает последние N часов как график

**Зависимости:** требует первой работающей линии (Фаза 5 — Facility Photo Feed + физическое строительство).

### Фаза 8 — Object Map

**Что:** Интерактивная карта на сайте с маркерами по каждому работающему объекту, % загрузки по live-данным с Фазы 7.

**Реальные локации (внутренний справочник, на сайте НЕ показывать имена):**
- Воронеж — комплекс активированного угля (первый)
- Краснодар — планируется
- Нижний Новгород — планируется

**Публичная подача (КРИТИЧНО — правило CLAUDE.md):** Карта не должна экспонировать названия российских городов. Варианты:
- Показывать только страну/регион уровнем выше («Eastern Europe — Hub 1», «Southern Region — Hub 2»)
- Замазать координаты до уровня области
- Использовать абстрактный globe-вид без географической привязки, только индикаторы «N комплексов работают»

Это решение фиксируется на этапе `/gsd-plan-phase 8`, не сейчас.

**Зачем:** Карта превращает «когда-нибудь будут заводы» в «вот три точки, вот их загрузка прямо сейчас».

### Фаза 9 — Transparency Report

> **v5-уточнение:** в дорожной карте токена это **Фаза 2** — запускается **после первой выплаты дивидендов**, а не на старте. (Нумерация «Фаза 9» — техническая, в рамках интриг прозрачности 7-9.)

**Что:** Каждая выплата дивидендов токенхолдерам сопровождается ссылкой на конкретную партию сорбента в блокчейне: «Эта выплата = выручка от партий #1247–#1289 с линии I».

**Технически:**
- При выплате — smart-contract публикует пакет с batch_ids и суммой
- Сайт рендерит ежеквартальный «Transparency Report»: партии → выручка → пул токена → выплата
- Партии цепляются к Proof-of-Processing записям (Фаза 7) для полной цепочки доказательств

**Зачем:** Финальное звено доверия. Не «мы заработали X — вот ваши Y%», а «вот конкретные тонны сорбента, проданные конкретным покупателям, по конкретной цене → вот ваша доля».

**Зависимости:** Фаза 7 (данные о партиях) + работающий контракт выплат.

---

### Логика трёх фаз вместе

Все три фазы строят одну воронку доверия:
1. **Фаза 7** доказывает, что **линия работает** (производство есть)
2. **Фаза 8** доказывает, что **линий несколько** (масштабирование идёт)
3. **Фаза 9** доказывает, что **выплаты честные** (выручка реально доходит до токенхолдера)

Без Фазы 7 две другие — маркетинг. С Фазой 7 — это первая в TON-экосистеме токенизация физического производства с end-to-end верификацией.
